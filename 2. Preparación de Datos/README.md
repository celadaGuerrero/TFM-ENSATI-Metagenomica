# 2. Preparación de Datos

Este apartado representa la comprobación del diseño longitudinal y la
preparación de las matrices utilizadas en el análisis. Cada participante
aporta una muestra basal (V00) y otra a los seis meses (V06); ambas visitas se
mantienen vinculadas y no se consideran observaciones independientes.

Los archivos de entrada no forman parte del repositorio. Los nombres de las
columnas describen su estructura esperada, pero no contienen códigos reales de
participantes, muestras o grupos del estudio.

## 2.1. Comprobación de Muestras

Se revisan las columnas necesarias, la ausencia de duplicados y la presencia
de las dos visitas para cada participante. También se comprueba que cada
participante permanezca en un único grupo de intervención.

## 2.2. Preparación de Matrices

Las tablas taxonómicas y funcionales se organizan con las muestras en filas y
las características en columnas. Posteriormente se comprueba la
correspondencia con los metadatos y se realiza el cierre de cada composición.
