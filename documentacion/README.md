# Documentación del análisis

La pregunta principal es si el cambio entre V00 y V06 difiere entre los tres
grupos. Cada participante aporta un cambio a esa comparación. Sus dos muestras
no se tratan como observaciones independientes.

Los programas, las bases de referencia y los parámetros se recogen en
[Métodos y versiones](metodos_y_versiones.md).

## Qué incluye el repositorio

El recorrido muestra el procesamiento de las lecturas, la preparación de
matrices y los análisis principales. Las figuras se hacen a partir de las
tablas de resultados.

El [análisis exploratorio](../03_analisis_estadistico/exploratorio_python/README.md)
estudia la predicción de pérdida de peso y la agrupación de perfiles basales.
Python entrena el modelo y obtiene los grupos. R prepara los resúmenes y las
tablas a partir de sus salidas.

Los intervalos por bootstrap, las comparaciones posteriores y los análisis
de sensibilidad se conservan en los scripts de trabajo del proyecto. Para
reproducir todas las tablas y anexos del TFM se necesitan esos scripts y los
datos de acceso restringido.

Las rutas y los nombres de muestra del repositorio son ejemplos. Cada carpeta
indica los archivos necesarios y las tablas que guarda.
